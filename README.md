# Portfólio de Wesley Ribeiro

Este repositório reúne meu portfólio pessoal, com projetos públicos do GitHub, stack observada no perfil, trajetória de estudos e descrição dos trabalhos desenvolvidos ao longo da jornada em desenvolvimento de software.

## Sobre mim

Sou estudante de Engenharia de Software e atualmente estou aprendendo no Projeto Social Garapuvu, com foco no desenvolvimento de software, lógica, front-end, práticas de qualidade e uso de IA generativa como apoio ao processo de criação, revisão e validação.

Essa base de estudo inclui aulas, desafios, mini-projetos e projetos práticos que ajudam a desenvolver não só a parte técnica, mas também a visão de solução, organização e qualidade no código.

## Contexto do aprendizado

O Projeto Social Garapuvu representa uma etapa importante da minha formação, em que tenho a oportunidade de:

- aprender desenvolvimento de software de forma prática;
- aplicar conceitos em projetos reais e mini-projetos;
- evoluir em lógica, HTML, CSS, JavaScript e Python;
- desenvolver uma visão de QA e qualidade de software;
- usar IA generativa para apoiar produtividade, revisão e testes.

Dentro desse contexto, o repositório do projeto contém aulas, desafios, mini-projetos e entregas práticas, incluindo experiências como o projeto Freelancer360.

## Stack atual

- Python
- JavaScript
- HTML5
- CSS3
- Git e GitHub
- IA generativa
- Copilot no Visual Studio Code
- Testes automatizados

## Estrutura do projeto

- `index.html` — página principal do portfólio
- `styles.css` — estilos visuais e responsividade
- `script.js` — carregamento dos repositórios e apresentação dos projetos
- `playwright.config.js` — configuração dos testes de responsividade
- `tests/portfolio-responsive.spec.js` — testes em desktop, tablet e mobile

## Publicação na Vercel

1. Faça o push deste repositório para o GitHub.
2. Conecte o projeto na Vercel.
3. Escolha a pasta raiz do projeto e faça o deploy.

## Observação

Os textos e a apresentação do portfólio foram elaborados com base no contexto do Projeto Social Garapuvu, nos repositórios públicos do GitHub e na trajetória de estudo em desenvolvimento de software com foco em qualidade e IA generativa.
